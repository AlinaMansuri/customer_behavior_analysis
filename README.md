# 🛍️ Customer Shopping Behavior Analysis

## 📌 Overview
Customer Shopping Behavior Analysis is an end-to-end data analytics project that explores customer purchasing patterns to generate meaningful business insights. The project covers the complete analytics lifecycle, including data cleaning, exploratory data analysis (EDA), SQL analysis, interactive Power BI dashboards, and project documentation.

---

## 📊 Dataset
The dataset contains customer shopping transactions with information such as:
- Customer demographics
- Product categories
- Purchase amount
- Subscription status
- Discounts and promo codes
- Shipping type
- Review ratings
- Purchase frequency

## 🚀 Project Workflow

### 1. Data Loading
- Imported the dataset using Pandas.
- Explored the dataset structure and data types.

### 2. Data Cleaning
- Handled missing values.
- Removed duplicate records.
- Standardized column names.
- Created new features for analysis.

### 3. Exploratory Data Analysis (EDA)
- Analyzed customer demographics.
- Studied purchasing behavior.
- Examined spending patterns.
- Visualized trends using charts and graphs.

### 4. SQL Analysis
Loaded the cleaned dataset into:
- PostgreSQL
- MySQL
- SQL Server

Executed SQL queries to analyze:
- Revenue by gender
- Customer segmentation
- Top-selling products
- Subscription behavior
- Discount usage
- Shipping preferences
- Revenue by age group

### 5. Power BI Dashboard
Created an interactive dashboard featuring:
- Sales Overview
- Customer Demographics
- Product Performance
- Subscription Analysis
- Revenue Insights
- KPI Cards
- Interactive Filters

### 6. Documentation
- Project Report
- Presentation (Created using Gamma AI)
- GitHub Repository

## 📈 Key Insights
- Identified high-value customer segments.
- Compared spending patterns of subscribers and non-subscribers.
- Identified top-performing products.
- Analyzed the impact of discounts on sales.
- Discovered purchasing trends across different customer age groups.

## ▶️ How to Run

1. Clone this repository.
2. Install the required Python libraries:

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2 pymysql
```

3. Open the Jupyter Notebook.
4. Run the notebook step by step.
5. Load the cleaned dataset into PostgreSQL, MySQL, or SQL Server.
6. Execute the SQL queries.
7. Open the Power BI dashboard to explore the insights.
